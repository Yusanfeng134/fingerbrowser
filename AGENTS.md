# Agent Instructions

- Treat this repository as a macOS-first Electron + React + TypeScript desktop app.
- Keep the MVP focused on compliant enterprise browser environment management: local configuration, isolated Chromium profiles, basic proxy setup, privacy normalization, and audit logs.
- Do not add bypass, evasion, credential abuse, captcha automation, or platform circumvention features.
- Never commit generated runtime data, Chromium binaries, browser profile directories, dependency folders, credentials, or local database files.
- Run `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`, and `npm run e2e` before claiming completion when feasible.
